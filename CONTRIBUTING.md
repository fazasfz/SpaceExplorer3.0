# Contributing to SpaceExplorer 3.0

Thank you for your interest in contributing to SpaceExplorer 3.0! Whether it's bug fixes, new features, or documentation improvements, all contributions are welcome.

## Getting Started

1. **Fork** the repository and **clone** your fork to your local machine:
   ```bash
   git clone [https://github.com/your-username/SpaceExplorer3.0.git](https://github.com/your-username/SpaceExplorer3.0.git)
   cd SpaceExplorer3.0
   
2. Backend Setup (Node.js):
Navigate to the backend directory and install dependencies:
```bash
cd backend
npm install
```
3. Frontend Setup (HTML / CSS / JS):
The frontend is built with vanilla HTML, CSS, and JavaScript. You can open the files directly or use a local development extension (like Live Server in VS Code) to view changes.

 ## Submitting a Pull Request
1. Create a descriptive branch for your changes:
```bash
git checkout -b feature/your-feature-name
```
2. Commit your changes with clear, concise messages.
3. Push your branch to your fork and open a Pull Request targeting the main branch.
